Mastyf Authority for GitHub

Privacy policy

Last updated 24 November 2026 · Mastyf Labs (Rudraneel Das)

Mastyf Authority for GitHub is a GitHub Action: a workflow you add to one of your own repositories. It runs on GitHub's runners, inside your GitHub account. Mastyf Labs receives no data from it: no events, no reports, no telemetry and no tokens.

What the workflow reads

Through GitHub's API, with the token you give it: the activity log of each repository it can see (pushes, force-pushes and branch deletions, with who and when), and repository and organisation settings (visibility, branch protection, rulesets, deploy keys, admins and owners). It does not read code, diffs, commit messages or file names.

What it keeps, and where

Only the weekly report, which it opens as an issue in your repository. To notice changes from one week to the next, it stores last week's settings, compressed, in a hidden comment in that issue. Nothing is stored anywhere else. Delete the issues and the history is gone.

Tokens

The workflow uses its own short-lived token, and optionally a read-only organisation token that you store as the secret MASTYF_ORG_TOKEN. Both stay in your GitHub; the workflow uses them only to call GitHub's API.

The code

Everything the workflow runs is open source and installed from the Action's own source at the version you reference: github.com/mastyf-ai/mastyf-authority. You can read it, or pin the Action to a commit you have reviewed.
