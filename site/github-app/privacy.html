Mastyf Authority for GitHub

Privacy policy

Last updated 24 November 2026 · Mastyf Labs (Rudraneel Das)

Mastyf Authority for GitHub ("the app") is a GitHub App that watches risky events in the organisations and accounts that install it, judges them the way Mastyf Authority would, and posts a weekly report. It runs in shadow mode: it never blocks, changes or reverts anything on GitHub. This page explains exactly what it receives, keeps and shares.

What the app receives

GitHub sends the app webhook events for the repositories you let it see: pushes, branch deletions, repositories deleted, made public or transferred, collaborators and owners added, deploy keys added, and branch protection or rulesets removed or changed. GitHub also tells the app when it is installed or uninstalled.

The app never fetches or keeps code, diffs, commit messages, file names or issue contents. GitHub requires read access to repository contents before it sends push events; the app uses only the event itself.

Where reports go

Weekly reports are posted as an issue in a private repository the app can see (preferably one named mastyf-reports or .github). If it can see no private repository, it posts nothing.

Who can see your data

Only Mastyf Labs, to run the app and to fix problems. We do not sell or share it, do not use it for advertising, and do not use it to train models shared with anyone else. The data is stored on infrastructure operated by Mastyf Labs.

Deleting your data

Uninstall the app in your organisation's or account's settings under GitHub Apps. When GitHub tells the app it was uninstalled, everything it kept about that installation is deleted immediately. You can also ask us to delete it at any time.

Contact

Questions or deletion requests: open an issue at github.com/mastyf-ai/mastyf-authority/issues (for anything sensitive, use a private report).
